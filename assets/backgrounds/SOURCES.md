# Background photo sources

Every file here is a real photograph in the public domain (CC0 or a
public-domain mark), sourced from Wikimedia Commons. No attribution is
legally required; this list exists so the provenance of anything we
publish can be checked.

Rules for anything added here: a real photograph of the natural world,
no human faces, no watermarks, no other brand's logo, no text baked in.
A filename whose prefix matches a theme (`relationships-05.jpg`) is
reserved for that theme; any other prefix is usable behind any quote.
